
# Cryptography Algorithms Implementation

## Project Overview

This project demonstrates the implementation of three fundamental cryptographic algorithms using Python. It explains how encryption, decryption, and hashing work through practical examples.

## Objectives

- Understand symmetric encryption.
- Understand public-key encryption.
- Learn how cryptographic hashing works.
- Verify data integrity.
- Compare Python and OpenSSL SHA-256 results.

## Technologies Used

- Kali Linux
- Python 3
- PyCryptodome
- OpenSSL
- SHA-256

## Algorithms Implemented

### 1. AES-256-GCM

AES (Advanced Encryption Standard) is a symmetric encryption algorithm.

- Uses a 256-bit secret key.
- Encrypts and decrypts data using the same key.
- GCM mode provides authentication and integrity verification.
- Demonstrates detection of modified encrypted data.

File: `aes_encryption.py`

### 2. RSA-2048

RSA is an asymmetric encryption algorithm.

- Uses a public key and a private key.
- Public key is used for encryption.
- Private key is used for decryption.
- Uses OAEP padding with SHA-256.

File: `rsa_encryption.py`

### 3. SHA-256

SHA-256 is a cryptographic hashing algorithm.

- Generates a 256-bit hash value.
- Produces a 64-character hexadecimal digest.
- Cannot be reversed through decryption.
- Demonstrates how a small message change produces a different hash.

File: `sha256_hashing.py`

## Installation

Clone or download this project.

Install the required Python library:

```bash
pip install -r requirements.txt
```

## How to Run

Run each program separately:

```bash
python aes_encryption.py
```

```bash
python rsa_encryption.py
```

```bash
python sha256_hashing.py
```

## OpenSSL Verification

The SHA-256 result can also be verified using OpenSSL:

```bash
openssl dgst -sha256 test_message.txt
```

The result should match the SHA-256 hash generated by the Python program.
